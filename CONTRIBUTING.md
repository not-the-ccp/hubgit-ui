# Contributing

HubGit uses short-lived branches and reviewable, single-purpose commits. Run
the relevant formatter, linter, type checker, and tests before submitting a
change. Public API changes must update the OpenAPI document, generated client,
fixtures, and adapter conformance tests together.

Reference work follows `docs/clean-room-protocol.md`. Do not commit GitHub
screenshots, private source maps, copied bundles, proprietary fonts, credentials,
or real private repository data.
